---

## Notes

- This account is created automatically when you run the database seed command: `npx prisma db seed`
- The demo account includes sample projects to help you understand the AHP workflow
- For production use, create your own account through the registration page
- **Security Warning:** Change or disable the demo account credentials in production environments

---

## Creating Additional Users

You can create new accounts by:
1. Using the **Register** page in the application
2. All new users will have isolated project spaces
3. Each user can only access their own projects

---

**Important:** Store these credentials securely and do not commit them to public repositories in production environments.
