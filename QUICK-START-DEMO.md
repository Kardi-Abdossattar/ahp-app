## 🎯 What to Do

### Step 1: View Projects
- After login, you'll see all 3 projects
- Each card shows title and description
- Click any project to open it

### Step 2: Explore Project Details
- See all criteria (decision factors)
- See all alternatives (options)
- View descriptions

### Step 3: View Results
- Click **"Calculate Results"** or **"View Results"**
- See final rankings with scores
- View criteria weights
- Check consistency ratios

### Step 4: Try Sensitivity Analysis
- Adjust criterion weights
- See how rankings change
- Test decision robustness

### Step 5: Export Report
- Click **"Generate PDF"**
- Get professional report with:
  - Decision hierarchy
  - Comparison matrices
  - Final rankings
  - Charts and analysis

## 💡 Tips

### Learning AHP
- Start with the **Laptop** project - easiest to understand
- Look at comparison values to see how preferences work
- Try changing criteria weights in sensitivity analysis

### Understanding Results
- Higher scores = better overall choice
- Criteria weights show what matters most
- Consistency ratio should be < 0.1

### Experimenting
- Click "Edit" to modify criteria or alternatives
- Add your own comparisons
- Create your own project from scratch

## 🔧 Making Changes

### Add New Alternative
1. Open any project
2. Click "Add Alternative"
3. Enter name and description
4. New comparisons will be needed

### Modify Comparisons
1. Go to "Compare" section
2. Change comparison values
3. Click "Recalculate" to update results

### Create New Project
1. Click "New Project" on dashboard
2. Define your goal
3. Add criteria (factors)
4. Add alternatives (options)
5. Make pairwise comparisons
6. Calculate results!
